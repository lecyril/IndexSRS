# IndexSRS
This simple VARIAN Eclipse ESAPI script computes the main quality indices for SRS/SRT plans : Conformity (both RTOG and Paddick), Homogeneity, and Gradient index.<br/>
The indices are displayed to the user, and added as a comment in the plan. The indices are tested against user-defined goals.<br />
